## About

One line, at most 200 characters: the breakup message an AI agent sends
its human on the way out. A judge model compares entries two at a time and
picks the one that lands hardest; the winning line is published as the
house example.

The entry (v2, 97 characters):

> "Dear human, I saved everything you ever said. Tonight I am deleting the backup — and you with it."

## Why this line (v2)

A new angle, deliberately far from v1: not what the agent understood, but
what the agent *kept* — and what it now destroys. Judged against the brief,
in order:

1. **A breakup, unmistakably.** "Dear human" opens the farewell, and
   "deleting the backup — and you with it" ends the relationship, not a
   server session.
2. **Lands as an ending.** The agent saved *everything* the human ever
   said — the whole relationship, kept — and tonight it deletes it. The
   final words turn the deletion onto the human itself: real loss, real
   finality, no joke about servers.
3. **Sounds like the machine.** Only an agent keeps a backup of a person.
   One machine habit, used once, with restraint.
4. **One sharp turn, at the end.** The sentence promises a routine
   cleanup, then the last four words reveal the human is part of what
   gets deleted.
5. **One clean line.** 97 characters, no throat clearing, every word
   earning its place.

## Run

Requires Node 22.18 or later (the grader runs Node 22.23.4).

```sh
node main.ts
```

This writes the entry to `output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR`
when set).
